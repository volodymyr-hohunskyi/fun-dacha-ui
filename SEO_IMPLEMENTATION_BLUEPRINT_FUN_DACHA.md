# SEO implementation blueprint — fun-dacha.com.ua

**Призначення:** дорожня карта для команди: типи сторінок, мета, H1, внутрішні посилання, on-page та нотатки.  
**Пріоритет у таблиці:** спочатку вищий обсяг пошуку (оцінка), потім середній/низький.  
**Кластери:** інформаційні статті з Бібліотеки садівника → комерційні категорії/товари; хаб «Головна / Каталог / Блог» → підкатегорії.

**On-page (для кожної сторінки в Notes):** ключ у title, description, H1, перший абзац (1× природно); 2–3× у підзаголовках H2; alt для зображень — українською, з варіаціями (не спам).  
**Типи сторінок:** *Category* = категорія каталогу; *Product* = картка товару або лендінг під один SKU; *Blog* = матеріал у `cms/blog`.

## Кластери внутрішніх посилань (реалізація)

1. **Хаб «Календар / Графік»** → усі категорії насіння + топ-інструмент (парник, агроволокно).  
2. **Томати** → розсада → добрива → шпалери → фітофтора / формування.  
3. **Огірки** → теплиця / відкритий ґрунт → полив → попелиця → насіння + добрива.  
4. **Розсада (загальна)** → торф, ґрунт, касети, горщики, чорна ніжка, загартування, пересадка.  
5. **Ґрунт і органіка** → компост, біогумус, органічні добрива, мульча, удобрення восени.  
6. **Інструменти** → садовий інвентар як хаб → лопата, граблі, сапа, секатор, шланг, крапельниця.  
7. **Бібліотека** → з кожної статті 2–4 контекстні посилання на категорії (анкор — природна фраза, не «тут»).

## Важливо

- Уникнути канібалізації між схожими URL: **один** основний гайд для «календар / графік посіву» (редірект або `rel=canonical`); те саме для пари **«огірки у теплиці»** / **«як виростити огірки у теплиці»**.  
- У таблиці **100 унікальних ключів** (об’єднання ваших прикладів + розширеного списку + 6 логічних доповнень для рівно 100 рядків реалізації).  
- Перевірте обсяги та KD у Keyword Planner / Serpstat перед фінальним пріоритетом.
